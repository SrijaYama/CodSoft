# CodSoft AI Internship Projects

Welcome to my internship projects repository! This repository contains the projects completed during my internship journey. These projects helped me improve my programming, logical thinking, and problem-solving skills using Python.

# Tasks Overview

## Task 1: AI Chatbot

Build a simple rule-based AI chatbot using Python.
The chatbot responds to user inputs based on predefined conditions using if-else statements.

### Features

* Greeting responses
* Answers simple questions
* Performs basic calculations
* Displays date and time
* Interactive conversation flow

---

## Task 2: Book Recommendation System

Create a simple recommendation system that suggests books based on user-selected categories.

### Features

* Multiple book categories
* Displays recommended books
* User-friendly menu system
* Content-based recommendation approach

---

## Task 3: Tic Tac Toe AI Game

Develop a Tic Tac Toe game where the user plays against the computer AI.

### Features

* Human vs Computer gameplay
* AI-based computer moves using Minimax Algorithm
* Win, lose, and draw detection
* Interactive command-line interface

---

# Technologies Used

* Python
* Conditional Statements
* Loops
* Functions
* Minimax Algorithm
